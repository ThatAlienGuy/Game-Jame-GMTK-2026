# Fulcrumit

A countdown-themed puzzle game made for **GMTK Game Jam 2026** (24-26 July 2026) by a team of 3.

Play it on itch.io: https://that-alien-guy.itch.io/fulcrumit

## About the game
The jam theme was **Countdown**. In Fulcrumit, levers and buttons control the doors in each level, and every lever and button has a countdown that measures how long it has been used.

- **Levers** open and close doors.
- **Buttons** rotate a door by 90 degrees each time they are pressed.

The game has 2 levels, each designed so it has no deadlocks and can be solved only in the intended way.

## Made with
- GameMaker, GML
- GameMaker Room Editor (level design)

## Result
Ranked in the top 60% for Enjoyment among jam entries.

## Level design process
Levels were first drawn on paper, then tested and reworked through many trials until no deadlock remained. After playtesting, the design was improved from player feedback.
